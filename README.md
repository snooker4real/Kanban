# Kanban

A kanban project using Spring Controllers (API)

**Stack** : Java 11, Maven, Spring Boot 2.5.5, MySQL

## Démarrage

### `kanbanJo/`

```bash
cd kanbanJo
./mvnw clean install   # construire et tester
./mvnw spring-boot:run   # démarrer l'application
./mvnw test   # lancer les tests
```
